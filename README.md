# 智记本地版

本地优先的 Android 记账 App，不需要微信登录。账目保存在当前设备，可通过坚果云 HTTPS WebDAV 上传和恢复 AES-GCM 加密备份。

源码仓库：`https://github.com/wolfsay123/icost`

## Android 安装

测试安装包位于 `release/zhiji-android-debug.apk`，支持 Android 7.0 及以上。将 APK 发到手机打开，按系统提示允许当前来源安装即可；详细安装、权限和真机验收步骤见 `docs/ANDROID.md`。

## 主要功能

- 多账本；支出、收入、转账、借入、借出、还款、收款、应付、应收。
- 现金、钱包、银行卡、信用、资产和负债账户；多币种与本位币折算。
- 分类、成员、标签、商家、照片、位置和记账模板。
- 月预算、分类预算、储蓄目标、周期账、分期和报销关联。
- 组合搜索、月度统计、JSON 完整备份、Excel XML 导入导出和回收站。
- 坚果云手动/自动加密同步、修订号冲突保护和 Android Keystore 凭据存储。
- 应用 PIN 锁、系统语音、通知/短信/无障碍候选和桌面小组件。

自动记账能力只生成候选，不会点击支付或绕过用户确认。系统权限都可拒绝，基础记账仍可正常使用。

## 本地启动

浏览器版本要求 Node.js 22 或更高：

```bash
npm start
```

打开 `http://127.0.0.1:5173`。

## 坚果云同步

在坚果云“账户信息 > 安全选项 > 第三方应用管理”生成应用密码，然后在“设置与同步”填写：

- 地址：`https://dav.jianguoyun.com/dav/`
- 账号：坚果云登录邮箱
- 应用密码：第三方应用管理生成的密码
- 云端路径：如 `智记/zhiji-backup.enc.json`
- 同步密钥：至少 8 位，用于本地加密与恢复

首次使用先测试连接再上传。恢复会覆盖当前设备数据；建议首次验收使用独立测试路径。

本地数据键仍为 `zhiji.local.v1`，数据内容会自动迁移到 schema v2。清除浏览器站点数据或 Android App 数据前务必先验证云端备份可恢复。
