# 变更记录

## 2026-08-11

- 数据模型升级到 v2：新增多账本隔离、9 类交易、信用账户、成员/标签/商家、多币种、照片/位置、模板、回收站和旧数据无损迁移。
- 新增预算、储蓄目标、周期账、分期、报销关联、组合搜索、完整统计，以及 JSON 和 Excel 2003 XML 导入导出。
- 坚果云 WebDAV 增加自动加密备份、修订号与跨设备冲突保护；Android 自动同步凭据改由 Keystore 加密保存。
- Android 增加语音输入、通知/短信/限定包名的无障碍候选、应用 PIN 锁、记账深链和桌面小组件；候选记录必须回到 App 确认，不自动提交账目。
- Android App 升级为 `0.3.0`（versionCode 2），最低 Android 7.0，目标 API 36。
- 修复照片与位置写入映射、多币种本位币统计、Excel 币种/汇率丢失，以及账户表单在双栏布局中越界的问题。
- 影响面：本地数据首次打开会自动迁移到 v2；新增可选系统权限，不授权不影响基础手动记账和 WebDAV 同步；不涉及微信登录、原厂云服务或生产环境。

## 2026-07-22

- 新增 Android App（`com.zhiji.local`，版本 `0.2.0`），支持 Android 7.0 及以上设备安装。
- Android 端通过 Capacitor 原生 HTTP 直接连接坚果云 HTTPS WebDAV，支持连接测试、创建目录、加密上传与下载恢复。
- 新增 Android 启动图标、启动屏、系统返回键处理，并禁止明文网络请求和系统级应用数据备份。
- 新增原生 WebDAV 请求测试与 APK 构建、验签流程；浏览器版本行为保持不变。
- 影响面：新增本地 Android 工程和调试安装包，不涉及应用商店、生产服务或用户真实坚果云账号。

## 2026-07-21

- 新增智记本地版：支持自然语言解析确认、手动记账、收支流水、分类、账户、预算和月度统计。
- 新增浏览器本地持久化，刷新页面后可继续使用当前账本。
- 新增坚果云 WebDAV 连接测试、AES-GCM 加密上传、下载恢复和本机同步配置清除；凭据不写入服务端文件。
- 影响面：新增本地 Web 应用、静态资源服务以及 `/api/webdav/*` 本地代理接口，不涉及生产环境。
