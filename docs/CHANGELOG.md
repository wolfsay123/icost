# 变更记录

## 2026-08-18

- Android 无障碍自动记账改为结构化候选流程：仅识别微信、支付宝支付结果页，过滤付款操作页，并提取收支类型、金额、商家、来源和时间。
- 自动候选进入本地持久队列，App 启动或返回前台时弹出；只有用户确认才写入账本，忽略或取消不会产生账目，无障碍服务不会点击或代操作支付。
- 新增跨通知/无障碍通道去重、已处理候选历史和敏感文本脱敏，避免重复入账并减少手机号、长编号及订单号暴露。
- Android App 升级为 `0.7.0`（versionCode 6）；影响面为自动记账候选、Android 升级安装和交易来源审计字段，数据模型仍为 v5。
- 数据模型升级到 v5：新增存钱计划集合及转账期次关联，v1-v4 数据首次打开自动迁移，JSON 与坚果云完整备份自动包含计划数据。
- 新增 365 天递增、52 周递增、每月定额和自定义存钱计划；365 天按 1 至 365 元累计 66,795 元，52 周按每周递增 10 元累计 13,780 元。
- 存钱计划绑定同币种来源账户与存款账户，每期需用户确认后生成真实转账；计划进度由有效转账反算，转账删除/恢复会同步回退/恢复期次，不改变总净资产。
- 存钱计划支持暂停、继续、删除和回收站恢复；删除计划保留历史转账，未完成计划占用的账户禁止删除，删除/恢复账本会连同计划关系处理。
- Android App 升级为 `0.6.0`（versionCode 5）；影响面为本地数据迁移、账户转账、计划管理、回收站、坚果云备份内容和 Android 升级安装。
- 数据模型升级到 v4：新增严格报销主记录、来源明细与到账/差额交易关联；v3 已报销旧数据自动迁移并保持关联可追溯。
- 信用账户按目标 APK 离线帮助口径生成账单周期：支出与转出计出账额，收入冲减应还，同期退款冲减出账额，跨期退款冲减应还或形成溢缴款，普通账户转入作为还款。
- 待报销支出、报销到账本金不进入普通收支与预算；支持多笔合并报销，实际到账差额单独生成收入或支出，删除到账时整组撤销并可从回收站恢复。
- 新增信用账单查看页；修复出账后信用账户收入未冲减已出账应还，以及移动端账户管理操作被长金额挤压的问题。
- Android App 升级为 `0.5.0`（versionCode 4）；影响面为信用账单、普通收支统计、预算、报销关联、旧备份迁移和 Android 升级安装。
- 数据模型升级到 v3：新增账户适用账本、退款子记录、应收应付结算关系、导入批次和信用账户扩展字段；v1/v2 数据自动幂等迁移，旧账户默认适用于原有全部账本。
- 账户管理新增按账本可用范围、隐藏、保留历史明细的软删除、余额差额补记和批量对账；删除账户不会删除既有流水。
- 新增支出/收入部分退款与多次退款，累计不得超过原金额；退款记录可撤销，账户余额、首页、预算、报表和组件统一按净额计算。
- 退款记录支持重新编辑金额、账户、日期和备注；编辑校验会扣除原记录后重算可退款上限，跨币种展示使用退款账户折合金额。
- 应收应付新增单笔部分结算和同类型、同账本、同币种批量结算；系统记录分摊关系并生成正式收支，删除/恢复结算明细会同步恢复来源状态。
- 信用账户按欠款计入负净资产，新增账单日当天归期、固定/间隔还款日、预计免息天数和同币种共享额度计算与配置。
- Android App 升级为 `0.4.0`（versionCode 3）；影响面为本地数据模型、账户余额、收支统计、预算与 Android 升级安装，不涉及微信登录、生产服务或用户坚果云凭据。
- Android ARM DBT 许可已接受；官方 Emulator 与 API 24 ARM64 镜像因 CDN 持续限速尚未完整安装，目标 APK 动态规则对照未完成；用户随后选择严格采用离线帮助公开口径，由 0.5.0 实现。

## 2026-08-11

- 数据模型升级到 v2：新增多账本隔离、9 类交易、信用账户、成员/标签/商家、多币种、照片/位置、模板、回收站和旧数据无损迁移。
- 新增预算、储蓄目标、周期账、分期、报销关联、组合搜索、完整统计，以及 JSON 和 Excel 2003 XML 导入导出。
- 坚果云 WebDAV 增加自动加密备份、修订号与跨设备冲突保护；Android 自动同步凭据改由 Keystore 加密保存。
- Android 增加语音输入、通知/短信/限定包名的无障碍候选、应用 PIN 锁、记账深链和桌面小组件；候选记录必须回到 App 确认，不自动提交账目。
- Android App 升级为 `0.3.0`（versionCode 2），最低 Android 7.0，目标 API 36。
- 修复照片与位置写入映射、多币种本位币统计、Excel 币种/汇率丢失，以及账户表单在双栏布局中越界的问题。
- 影响面：本地数据首次打开会自动迁移到 v2；新增可选系统权限，不授权不影响基础手动记账和 WebDAV 同步；不涉及微信登录、原厂云服务或生产环境。

## 2026-07-22

- 新增 Android App（`com.zhiji.local`，版本 `0.2.0`），支持 Android 7.0 及以上设备安装。
- Android 端通过 Capacitor 原生 HTTP 直接连接坚果云 HTTPS WebDAV，支持连接测试、创建目录、加密上传与下载恢复。
- 新增 Android 启动图标、启动屏、系统返回键处理，并禁止明文网络请求和系统级应用数据备份。
- 新增原生 WebDAV 请求测试与 APK 构建、验签流程；浏览器版本行为保持不变。
- 影响面：新增本地 Android 工程和调试安装包，不涉及应用商店、生产服务或用户真实坚果云账号。

## 2026-07-21

- 新增智记本地版：支持自然语言解析确认、手动记账、收支流水、分类、账户、预算和月度统计。
- 新增浏览器本地持久化，刷新页面后可继续使用当前账本。
- 新增坚果云 WebDAV 连接测试、AES-GCM 加密上传、下载恢复和本机同步配置清除；凭据不写入服务端文件。
- 影响面：新增本地 Web 应用、静态资源服务以及 `/api/webdav/*` 本地代理接口，不涉及生产环境。
