## 离线帮助规则

APK 内置帮助中心补充确认了以下公开业务口径，但删除恢复、跨设备同步和异常输入仍需动态验证：

- 信用账户的支出和转出计入所属账单周期的出账金额；收入不降低出账金额，但降低实际应还金额；还款使用普通账户转入信用账户，不重复计入支出。
- 同账期交易的退款降低该期出账金额；上期交易在本期退款时不回写上期出账金额，只降低应还金额，已还清时形成溢缴款抵扣后续应还。
- 待报销支出不计入普通支出统计和预算，报销到账也不计入普通收入；实际到账与所选待报销金额的差额才生成收入或支出。
- 报销确认支持勾选多笔待报销明细并填写实际到账金额；复杂的分批、部分和预付款场景建议通过借贷账户处理。
- 同一收支明细支持多次退款，退款记录可以继续新增、编辑和删除。

智记 0.5.0 已按上述公开口径独立实现信用账期、出账额、应还额、同/跨期退款、溢缴款、转账还款，以及批量报销、普通收支排除、差额入账和成组删除恢复。领域测试与本地浏览器流程已验证，但由于目标 APK 尚未完成 ARM 模拟器或真机动态操作，这只能证明“符合帮助文案口径”，不能宣称所有隐藏边界与原应用完全一致。

智记 0.7.0 的自动记账采用独立可审计规则：仅将微信/支付宝支付结果页转成脱敏候选，并要求用户确认后入账；操作页拒绝、持久队列和跨通道去重已由本地测试验证。目标 APK 的自动识别触发条件及系统行为尚未动态对照，因此不宣称隐藏规则完全一致。

智记 0.8.0 依据上述静态可观察结构重排导航与页面层级，使用独立配色和 Lucide 开源图标，没有复制目标 APK 的品牌图标、插画、启动图或其他专有素材。当前只能确认结构映射，目标 APK 动态间距、动画及状态变化仍待真机对照。

## 技术边界

- 应用使用 `com.sagittarius.v6.StubApplication` 和 `libbaiduprotect.so`，业务代码受百度加固保护；JADX 静态结果主要是资源类，无法把原业务源码作为实现依据。
- 当前实现是依据可验证的 Manifest/资源功能面和独立业务规则重新开发，不是复制原 APK 源码。
- 动态页面路径仍需 ARM 模拟器或安卓真机。`android-sdk-arm-dbt-license` 已获用户同意并接受，但官方组件下载受限，镜像尚未完整安装。
