# 智记 Android 本地版实施计划

更新日期：2026-08-11

## 北极星

交付一个可安装到 Android 手机、无需微信登录、数据本地优先且能通过坚果云 WebDAV 加密同步的完整记账 App；所有完成状态都以真实交互、持久化数据和 APK 验证为准。

## 角色与关键路径

- 个人用户：新建账本 -> 记账 -> 搜索/统计 -> 备份 -> 换机恢复。
- 家庭记账者：维护成员、分类、标签、商家和共同账户 -> 分账 -> 查看预算与报表。
- 经常出差用户：记录附件和位置 -> 标记待报销 -> 关联报销收入。
- 信用消费用户：维护信用账户 -> 分期/还款 -> 查看余额与计划。

## 边界与后续验收

- Android 36 ARM 模拟器安装要求单独接受 `android-sdk-arm-dbt-license`；需用户明确回复“同意 ARM DBT 许可”后才能继续目标 APK 和本 App 的模拟器动态验收。
- ADB 当前没有连接安卓设备，因此不能宣称短信、通知、无障碍、语音、定位、桌面组件和系统返回键已在真机通过。
- 不修改 VPN、Clash 或系统代理；不接入微信登录；不触碰生产服务。
- 目标 APK 仅用于理解用户明确提供的软件行为，不复制其受保护源码、密钥、品牌资源或签名。
