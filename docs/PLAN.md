# 智记 Android 本地版功能对齐计划

更新日期：2026-08-18

## 北极星

交付一个可安装到 Android 手机、无需微信登录、数据本地优先并能通过坚果云 WebDAV 加密同步的记账 App；对“小星记账”的对齐只以可观察页面、业务结果、持久化数据和真机行为为准。

## 对齐边界

- 独立实现目标 APK 中可观察到的本地记账功能与业务规则，不复制加固源码、品牌名称、图标素材、密钥、签名或付费校验。
- 微信授权登录、微信支付、原厂云服务、阿里云盘、广告和 VIP 激活不在范围内；云端仅保留坚果云 WebDAV。
- “功能一致”包括入口、校验、金额计算、关联数据、删除/恢复影响和异常路径；只有同名页面不算完成。
- 目标 APK 的业务代码受百度加固保护。动态行为未验证前，只能标记为“静态推定”，不能宣称与原应用逻辑完全一致。

## 关键角色与路径

- 日常记账者：建账本 -> 选账户 -> 记录/拆分/退款 -> 日历与搜索 -> 报表。
- 信用消费用户：配置信用卡 -> 形成账单 -> 还款/分期 -> 额度与到期提醒 -> 对账。
- 家庭记账者：维护成员、分类、标签组、商家组和共享账户范围 -> 分摊 -> 预算。
- 报销与应收应付用户：登记待收/待付或待报销 -> 部分/批量结算 -> 回看原始关联。
- 换机用户：本地加密备份 -> 坚果云上传 -> 新设备恢复 -> 冲突处理。

## 实施阶段

### 阶段 A：动态基线与规则冻结

1. 在隔离的 Android 模拟器安装目标 APK 与智记 APK。
2. 按差距矩阵录制页面路径、输入条件、结果和异常提示，不导出或复制目标私有资源。
3. 将静态推定更新为“动态确认”或“与目标不同”，对涉及金额逻辑的差异先列选项再实现。

核验标准：每个 P0 项至少有正常、边界、撤销/删除三类证据；目标 APK 无法运行的项明确保持“待确认”。

阻塞项：Android 36 ARM 镜像需要单独接受 `android-sdk-arm-dbt-license`。只有用户明确回复“同意 ARM DBT 许可”后才可安装。

### 阶段 B：财务内核与数据模型 v5

1. 为账户范围、退款子记录、结算关系、严格报销关系、信用账期、存钱计划和生成任务来源定义 v5 数据契约。
2. 实现 v1/v2/v3/v4 -> v5 幂等迁移，保留现有账本、明细、附件、同步修订号和回收站数据。
3. 将金额计算集中到领域模块，页面只调用规则，不自行拼算余额。
4. 完成 P0 的账户、信用卡、退款、应收应付和报销链路。

核验标准：迁移前后现有余额和收支不变；跨月账期、部分退款、批量结算、撤销与回收站用例全部通过；同步往返后关联不丢失。

### 阶段 C：明细、预算、周期和导入

1. 完成拆分/关联/批量操作、预算目标、周期账和分期。
2. 新增微信、支付宝和通用模板解析器，导入必须先预览再入库。
3. 导入记录使用批次 ID，可整体撤销并报告失败行，不修改原文件。

核验标准：金额守恒、周期幂等、预算跨周期和重复导入测试通过；脱敏样例可复现成功/失败结果。

### 阶段 D：报表、日历与管理界面

1. 补齐资产/负债/净资产、账户明细、日历热力图。
2. 补齐标签组、商家组、自定义账户类型、排序、筛选和隐藏项。
3. 以 375x812、安卓常用手机尺寸和桌面调试尺寸截图逐页对照。

核验标准：报表可由固定数据集独立手算复核；页面无横向溢出、遮挡和不可达操作；筛选结果与导出结果一致。

### 阶段 E：Android 与坚果云端到端验收

1. 构建并验签新 APK，在模拟器和用户安卓真机安装升级。
2. 验证通知、短信候选、无障碍候选、语音、定位、照片、桌面组件和应用锁。
3. 使用用户自己的坚果云应用密码完成双安装备份、恢复与冲突演练；凭据只进 Android Keystore。

核验标准：升级不丢数据；系统能力需要真实触发证据；坚果云需看到远端文件并在另一安装恢复出同一账本。HTTP 成功或单次上传不等于恢复闭环。

## 工程约束

- 每个阶段先写领域测试，再接页面；共享计算规则修改前扫描全部调用点。
- 金额按最小货币精度处理，禁止用 UI 格式化值参与计算。
- 自动记账必须先形成候选并由用户确认；周期后台任务使用稳定幂等键。
- 所有数据结构变更必须兼容旧备份；不能识别的新版本备份禁止覆盖本地数据。
- 对外可见功能、数据格式和 APK 版本变更写入 `docs/CHANGELOG.md`。
- 不修改 VPN、Clash、系统代理，不接触生产服务，不在仓库记录坚果云账号或应用密码。
