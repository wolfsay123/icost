# 本地验收记录

验收日期：2026-08-11

## 已验证

- 数据模型从 v1 自动迁移到 v2，原余额、预算和流水不变；重复规范化保持业务 ID。
- 多账本复制默认分类并隔离流水、预算和维度数据；账户作为全局资产共享。
- 支出、收入、转账、借入、借出、还款、收款、应付、应收按业务语义更新余额，待处理款项不提前影响资金余额。
- 搜索支持关键词、类型、账户、日期和金额区间组合；统计、分类预算和报销金额使用统一的本位币口径。
- 周期账按周/月/年推进并处理月末；分期最后一期吸收舍入差额；报销收入与原支出建立关联。
- 多币种浏览器实测：10 USD、汇率 7.2 的支出显示原币 `$10`，本位币支出与余额变化均为 `¥72`；10 USD 初始余额账户折算为 `+¥72`。
- 照片附件与经纬度可写入账目；模板可回填交易类型、金额、币种、汇率和维度。
- JSON 完整备份可恢复；Excel 2003 XML 可导出/导入并保留币种和汇率，同时兼容不含这两列的旧文件。
- 本地 WebDAV 完成 AES-GCM 加密上传、下载恢复、自动上传、修订号和不同设备冲突拦截；取消覆盖后保留本地未同步数据。
- 应用锁错误 PIN 被拒绝，正确 PIN 可解锁；本地状态只保存 PBKDF2 派生值和盐，不保存明文 PIN。
- 375x812 与 1440x900 视口均无横向溢出或可见控件越界；浏览器控制台无错误或警告。
- `npm run check` 为 15/15，`npm audit` 为 0 个已知漏洞。
- APK 构建成功、v2 签名有效；包名、版本、权限、系统组件和自定义 DEX 类均从 APK 本体独立确认。

## 验收边界

- 未使用用户真实坚果云账号和应用密码，不把本地 Mock WebDAV 成功当作坚果云实网成功。
- ADB 当前无已连接设备，APK 尚未在实体安卓手机上安装；语音、短信、通知使用权、无障碍、定位、应用锁返回前台和桌面组件需真机逐项授权验证。
- 目标 APK 受百度加固保护；静态审计不能证明每个隐藏交互细节与原版逐像素或逐规则一致。
- 验收截图中的账目均为本地测试数据；全新安装不会预置这些流水。
