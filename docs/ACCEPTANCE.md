# 本地验收记录

验收日期：2026-08-18

## 已验证

- 数据模型从 v1/v2/v3/v4 自动迁移到 v5，原余额、预算和流水不变；旧报销关联与新增存钱计划、转账期次均保持稳定业务 ID。
- 多账本隔离流水、预算和维度数据；账户可限制适用账本、隐藏、软删除并从回收站恢复，历史流水保留原账户引用。
- 支出、收入、转账、借入、借出、还款、收款、应付、应收按业务语义更新余额，待处理款项不提前影响资金余额。
- 搜索支持关键词、类型、账户、日期和金额区间组合；统计、分类预算、退款和报销金额使用统一的本位币净额口径。
- 100 元支出部分退款 30 元后，余额、月支出和预算均按 70 元统计；刷新后退款子记录仍存在，删除退款记录可逆。
- 100 元应收先结算 40 元，再与另一笔 20 元应收批量结算 80 元；第二次按 60/20 分摊，两笔来源均转为已结算并生成一笔正式收入。
- 信用账户按欠款计入负净资产；账单周期覆盖支出/转出、收入冲减应还、同/跨期退款、转账还款与溢缴款。浏览器固定数据实测出账 `¥100.00`、本期剩余应还 `¥10.00`，与账户总欠款一致。
- 两笔待报销合计 `¥150.00`，实际到账 `¥170.00` 时，仅 `¥20.00` 差额进入普通收入；删除到账会同时撤销到账本金与差额并恢复两笔待报销状态，从回收站可整组恢复。
- 365 天计划固定为 365 期、首期 `¥1.00`、每期递增 `¥1.00`、总额 `¥66,795.00`；52 周计划固定为 52 期、首期 `¥10.00`、每期递增 `¥10.00`、总额 `¥13,780.00`。
- 浏览器实测创建 365 天计划并执行首期后，工资卡减少 `¥1.00`、存款账户增加 `¥1.00`、总净资产保持 `¥1,000.00`；下一期自动为 `2026-08-19`、`¥2.00`。
- 暂停/继续、删除/恢复首期转账、账户删除保护、计划回收站及含计划账本的删除恢复均通过；计划进度由现存有效转账反算。
- 周期账按周/月/年推进并处理月末；分期最后一期吸收舍入差额；报销主记录、来源支出、到账本金和差额交易保持稳定关联。
- 多币种浏览器实测：10 USD、汇率 7.2 的支出显示原币 `$10`，本位币支出与余额变化均为 `¥72`；10 USD 初始余额账户折算为 `+¥72`。
- 照片附件与经纬度可写入账目；模板可回填交易类型、金额、币种、汇率和维度。
- JSON 完整备份可恢复；Excel 2003 XML 可导出/导入并保留币种和汇率，同时兼容不含这两列的旧文件。
- 本地 WebDAV 完成 AES-GCM 加密上传、下载恢复、自动上传、修订号和不同设备冲突拦截；取消覆盖后保留本地未同步数据。
- 应用锁错误 PIN 被拒绝，正确 PIN 可解锁；本地状态只保存 PBKDF2 派生值和盐，不保存明文 PIN。
- 自动候选解析单元测试覆盖微信支出、支付宝收款/退款、操作页与无结果页拒绝、敏感文本脱敏、通知与无障碍跨通道去重，共 5/5 通过。
- 浏览器移动端实测：启动自动弹出微信候选，确认后只生成一笔带候选 ID 的交易；第二条支付宝候选取消后仍保留，忽略后移除；重新注入首条候选不会重复入账，横向溢出为 0，控制台无错误。
- 375x812 与 1440x1000 最新 v5 存钱计划流程横向溢出均为 0；计划金额、下一期和操作区可读，浏览器控制台无错误。
- `npm run check` 为 29/29；`npm audit --json` 为 0 个已知漏洞。
- 已知未闭环：信用提醒/支付推荐及 P1/P2 功能仍在差距矩阵中；目标 APK 未完成动态操作对照，不得据此宣称所有功能和隐藏边界完全一致。
- APK 0.7.0 构建成功、v2 签名有效；包名 `com.zhiji.local`、versionCode 6、最低 API 24、目标 API 36 均从 APK 本体独立确认。

## 验收边界

- 未使用用户真实坚果云账号和应用密码，不把本地 Mock WebDAV 成功当作坚果云实网成功。
- ADB 当前无已连接设备，APK 尚未在实体安卓手机上安装；自动候选已完成解析和浏览器交互验证，但微信/支付宝真实无障碍事件、语音、短信、通知使用权、定位、应用锁返回前台和桌面组件仍需真机逐项授权验证。
- ARM DBT 许可已接受。Android Emulator 首次通过 SDK Manager 下载到约 220 MB 后传输失败，现使用 Google 官方包断点续传；目标 APK 动态对照仍未完成。
- 目标 APK 受百度加固保护；当前信用账期规则来自静态文案与常规财务规则，不能冒充已经逐项动态验证为原版逻辑。
- 验收截图中的账目均为本地测试数据；全新安装不会预置这些流水。
